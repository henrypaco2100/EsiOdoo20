# Correspondencia funcional

| Función de Odoo 13 revisada | Implementación en ESI Finanzas 20 |
|---|---|
| Informes padre/hijos, secuencia y código | Estructuras y títulos configurables |
| Cuentas explícitas y tipos de cuenta | Selección de cuentas, subcuentas y `account_type` |
| Valor de otro informe | Referencia a título/informe de la misma compañía |
| Resultado por suma/resta | Fórmulas con varias operaciones |
| Signo y formatos por nivel | Signo, estilos y nivel de detalle |
| Detalle plano o jerárquico | Tres opciones: sin detalle, plano, jerárquico |
| Diarios del informe | Incluir/excluir globalmente y excluir por título |
| Débito/crédito | Columnas opcionales, también con comparación |
| Comparación de períodos y etiqueta | Fechas, etiqueta y variación |
| Moneda | API nativa por compañía y fecha, tasa final o histórica |
| Analíticas | Distribución porcentual y modo de asientos completos |
| Contactos y desglose | Selección múltiple y detalle informativo |
| Saldo inicial y orden del Mayor | Saldo opcional, fecha/diario-contacto |
| Mayor clásico/minimalista | Ambos formatos con moneda de origen opcional |
| Cuentas de flujo y clasificación | Categorías jerárquicas y filtros, flujo por actividad/categoría |
| PDF, Excel y vista previa | Mismo motor y filtros para las tres salidas |
| Multisucursal | Matriz, sucursal y selección múltiple con permisos nativos |

La adaptación no importa automáticamente configuraciones almacenadas en otra base Odoo 13. El paquete recibido contiene código y plantillas, no un volcado de sus registros personalizados.
